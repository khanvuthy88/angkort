# Angkort API Stabilized Routes Documentation

Date: 2026-03-22

Scope:
- Auth routes
- Shop create route
- Product create route
- Variant create route
- Secured sale list route

Base URL:
`/angkort/api/v1`

Auth model:
- Public/no session routes: `login`, `refresh`
- Bearer-protected routes: `logout`, `shop`, `product`, `variant`, `sale`
- Bearer header format: `Authorization: Bearer <access_token>`

## 1. POST `/login`

Purpose:
Authenticate a user and issue access and refresh tokens.

Accepted body:
- `application/json`
- `application/x-www-form-urlencoded`

Params:

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `username` | string | Yes | User login |
| `password` | string | Yes | User password |

Success response:
Status: `200`

```json
{
  "status": true,
  "message": "Login successful",
  "data": {
    "access_token": "<jwt>",
    "refresh_token": "<jwt>",
    "token_type": "Bearer",
    "expires_in": 1800,
    "user_id": 12,
    "username": "merchant.owner@example.com",
    "name": "Merchant Owner",
    "email": "merchant.owner@example.com",
    "roles": "MERCHANT",
    "shops": [
      {
        "id": 101,
        "name": "Owner Shop",
        "phone": "012345678",
        "customer_address": "Owner Street"
      }
    ]
  }
}
```

Error responses:

Missing params or invalid JSON:
Status: `400`

```json
{
  "status": false,
  "message": "Missing required fields",
  "error": "Username and password are required"
}
```

Invalid credentials:
Status: `401`

```json
{
  "status": false,
  "message": "Authentication failed",
  "error": "Invalid credentials"
}
```

Internal error:
Status: `500`

```json
{
  "status": false,
  "message": "Internal server error",
  "error": "An unexpected error occurred during login"
}
```

## 2. POST `/refresh`

Purpose:
Generate a new access token using a valid refresh token.

Accepted body:
- `application/json`
- `application/x-www-form-urlencoded`

Params:

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `refresh_token` | string | Yes | Refresh token returned by login |

Success response:
Status: `200`

```json
{
  "status": true,
  "message": "Token refreshed successfully",
  "data": {
    "access_token": "<jwt>",
    "token_type": "Bearer",
    "expires_in": 1800
  }
}
```

Error responses:

Missing token:
Status: `400`

```json
{
  "status": false,
  "message": "Missing required field",
  "error": "Refresh token is required"
}
```

Invalid or expired refresh token:
Status: `401`

```json
{
  "status": false,
  "message": "Authentication failed",
  "error": "Invalid or expired refresh token"
}
```

## 3. POST `/logout`

Purpose:
Revoke the active access token.

Headers:

| Name | Required | Description |
|------|----------|-------------|
| `Authorization` | Yes | `Bearer <access_token>` |

Success response:
Status: `200`

```json
{
  "status": true,
  "message": "Successfully logged out"
}
```

Error responses:

Missing header:
Status: `400`

```json
{
  "status": false,
  "message": "Access token missing",
  "error": "Authorization header is required"
}
```

Invalid token:
Status: `401`

```json
{
  "status": false,
  "message": "Authentication failed",
  "error": "Invalid access token"
}
```

## 4. POST `/shop`

Purpose:
Create a new shop for the authenticated merchant.

Auth:
Bearer token required.

Recommended body:
`multipart/form-data`

Params:

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | string | Yes | Shop name |
| `phone` | string | Yes | Shop phone |
| `customer_address` | string | Yes | Shop address |
| `email` | string | No | Shop email |
| `wifi_name` | string | No | Comma-separated Wi-Fi names |
| `shop_latitude` | string/number | No | Shop latitude |
| `shop_longitude` | string/number | No | Shop longitude |
| `shop_wifi_ids` | JSON string | No | Wi-Fi entries, example `[{"name":"Guest","password":"1234"}]` |
| `shop_open_hour_ids` | JSON string | No | Opening hours, example `[{"day":"0","open":"08:00","close":"20:00"}]` |
| `shop_banner` | file | No | Shop banner image |

Success response:
Status: `201`

```json
{
  "id": 102,
  "name": "Fresh Shop"
}
```

Error responses:

Validation error:
Status: `400`

```json
{
  "status": "error",
  "message": "Failed to create shop",
  "statusCode": "400",
  "errors": [
    {
      "name": "phone",
      "message": "Phone number is required"
    }
  ]
}
```

Unauthorized:
Status: `401`

Response may be generated by Odoo auth middleware for missing or invalid bearer tokens.

Internal error:
Status: `500`

```json
{
  "status": "error",
  "message": "Failed to create shop",
  "statusCode": "500",
  "errors": [
    {
      "name": "general",
      "message": "..."
    }
  ]
}
```

## 5. POST `/shop/{shop_id}/product`

Purpose:
Create a product inside a shop owned by the authenticated user.

Auth:
Bearer token required.

Accepted body:
- `application/json`
- `multipart/form-data`

Path params:

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `shop_id` | integer | Yes | Target shop ID |

Body params:

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | string | Yes | Product name |
| `code` / `default_code` | string | No | Internal reference |
| `description` | string | No | Product description |
| `sale_price` / `list_price` | number | No | Product sale price |
| `category_id` / `categ_id` | integer | No | Product category ID |
| `type` | string | No | `consu` or `service` |
| `image` | base64 string or file | No | Product image |
| `variant_ids` | integer array | No | Attach all values from listed attributes |
| `attribute_lines` | array | No | Explicit variant/value mapping |

`attribute_lines` example:

```json
[
  {
    "attribute_id": 14,
    "value_ids": [55]
  }
]
```

Success response:
Status: `201`

```json
{
  "data": {
    "id": 55,
    "name": "Noodle Soup",
    "code": "SOUP-001",
    "description": "House noodle soup",
    "sale_price": 4.5,
    "image": "",
    "category": {
      "id": 1,
      "name": "All"
    },
    "options": [],
    "choices": [],
    "createdAt": "2026-03-22T02:06:47",
    "updatedAt": "2026-03-22T02:06:47",
    "publishedAt": "2026-03-22T02:06:47"
  }
}
```

Error responses:

Missing product name:
Status: `400`

```json
{
  "status": "error",
  "message": "Failed to create product",
  "statusCode": 400,
  "errors": [
    {
      "name": "name",
      "message": "Product name is required"
    }
  ]
}
```

Shop not found:
Status: `404`

```json
{
  "status": "error",
  "message": "Failed to create product",
  "statusCode": 404,
  "errors": [
    {
      "name": "shop_id",
      "message": "Shop not found"
    }
  ]
}
```

Ownership error:
Status: `403`

```json
{
  "error": "Unauthorized: You can only modify shops you own"
}
```

## 6. POST `/shop/{shop_id}/product/variant`

Purpose:
Create a product attribute/variant for a shop owned by the authenticated user.

Auth:
Bearer token required.

Path params:

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `shop_id` | integer | Yes | Target shop ID |

Form params:

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | string | Yes | Variant name, unique per shop |
| `create_variant` | string | Yes | `no_variant` or `always` |
| `display_type` | string | Yes | `multi` or `radio` |

Success response:
Status: `201`

```json
{
  "id": 14,
  "name": "Spice Level",
  "create_variant": "always",
  "display_type": "radio"
}
```

Error responses:

Missing fields:
Status: `400`

```json
{
  "status": "error",
  "message": "Failed to create variant",
  "statusCode": "400",
  "errors": [
    {
      "name": "display_type",
      "message": "Display type is required"
    }
  ]
}
```

Duplicate name:
Status: `400`

```json
{
  "status": "error",
  "message": "Failed to create variant",
  "statusCode": "400",
  "errors": [
    {
      "name": "name",
      "message": "Attribute with name Spice Level already exists"
    }
  ]
}
```

Ownership error:
Status: `403`

```json
{
  "error": "Unauthorized: You can only modify shops you own"
}
```

## 7. GET `/sale`

Purpose:
List sale orders visible to the authenticated user.

Auth:
Bearer token required.

Visibility rules:
- admin: all sale orders
- merchant: sale orders for owned shops
- other authenticated user: sale orders for their own partner

Query params:

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | integer | No | Page number, default `1` |
| `limit` | integer | No | Page size, max `100` |
| `search` | string | No | Search by order name or customer name |
| `sort` | string | No | One of `id`, `name`, `date_order`, `amount_total`, `create_date` |
| `order` | string | No | `asc` or `desc` |
| `filter_state` | string | No | `draft`, `sent`, `sale`, `done`, `cancel` |
| `filter_date_from` | string | No | `YYYY-MM-DD` |
| `filter_date_to` | string | No | `YYYY-MM-DD` |
| `filter_amount_min` | number | No | Minimum total amount |
| `filter_amount_max` | number | No | Maximum total amount |
| `filter_customer` | integer | No | Partner ID |

Success response:
Status: `200`

```json
{
  "data": [
    {
      "id": 77,
      "name": "S00077",
      "partner_name": "Merchant Owner",
      "date_order": "2026-03-22",
      "amount_total": 4.5,
      "state": "draft",
      "createdAt": "2026-03-22T02:00:15",
      "updatedAt": "2026-03-22T02:00:15",
      "publishedAt": "2026-03-22T02:00:15"
    }
  ],
  "meta": {
    "pagination": {
      "page": 1,
      "pageSize": 20,
      "pageCount": 1,
      "total": 1
    },
    "keyword": {
      "search": null,
      "sort": "date_order",
      "order": "desc",
      "filter": {}
    }
  }
}
```

Unauthorized:
Status: `401`

Response is produced by the bearer auth middleware if the token is missing, invalid, expired, or revoked.

## Recommended Postman Flow

1. Import `Angkort_API_Stabilized_Routes_Postman_Collection.json`
2. Set `base_url`
3. Run `Login`
4. Run `Create Shop` if you need a fresh shop
5. Run `Create Variant`
6. Optionally set `variant_value_id` manually after creating values in your database
7. Run `Create Product`
8. Run `Sale List (Secured)`
